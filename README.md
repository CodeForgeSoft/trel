# Trel — PWA для поиска маршрутов

**Статус: раннее планирование.** Проект в стадии идеи и прототипирования.
Код ещё не написан — сейчас формируем видение, дизайн-систему и архитектуру.

PWA для поиска, swipe-рекомендаций и отметок маршрутов.

---

## Планируемый функционал

| Возможность | Описание |
|-------------|----------|
| **Каталог трейлов** | 70+ маршрутов с поиском, фильтром по сложности и региону |
| **Swipe-рекомендации** | Tinder-like карточки: вправо — «хочу посетить», влево — пропустить |
| **Интерактивная карта** | Маркеры точек входа и GPX-треки |
| **Детальная страница** | Фото, статистика, как добраться, достопримечательности |
| **Списки пользователя** | Три состояния для каждого трейла: «Не был», «Хочу посетить», «Я тут был» |
| **Рейтинг** | Оценка 1–5 после отметки «Я тут был» |
| **Авторизация** | JWT, регистрация/логин, история просмотров |
| **Админ-панель** | Управление трейлами, пользователями, списками, оценками |
| **PWA** | Установка на телефон, офлайн (manifest + service worker) |
| **GPX/KML** | Скачивание треков, отрисовка на карте |
