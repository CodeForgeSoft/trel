# Дизайн-система

Система для ведения дизайна проекта - от черновиков до токенов.
В разработке - наполняется по мере готовности макетов.

---

## Текущее состояние

| Раздел | Статус |
|--------|--------|
| `tokens.json` | Готов — базовые цвета, отступы, радиусы, тени |
| `wireframes/` | В работе — UX-схемы в Excalidraw |
| `screens/` | Ожидают утверждения вайрфреймов |
| `components/` | Будут экспортированы после чистовых макетов |

---

## Структура папок

```
design/
├── wireframes/         ← UX-схемы и черновики (Excalidraw)
├── screens/            ← Финальные мокапы экранов (WebP, light + dark)
├── components/         ← Состояния UI-компонентов (SVG)
├── tokens.json         ← Дизайн-токены (цвета, отступы, радиусы, тени)
└── README.md           ← Этот файл
```

---

## Инструменты

| Инструмент | Назначение | Формат |
|------------|-----------|--------|
| **Penpot** | Дизайн-макеты, компоненты, экспорт | `.penpot` (ZIP) |
| **Excalidraw** | Wireframes, UX-схемы | `.excalidraw` (JSON) |
| **SVG** | Состояния компонентов | `.svg` |
| **WebP** | Экспорты экранов | `.webp` |

---

## Дизайн-токены

Файл `tokens.json` — единый источник истины для визуальных переменных.

Синхронизация с кодом:
1. **Дизайнер** меняет токен в `tokens.json`
2. **Разработчик** переносит значение в `tailwind.config.ts` и `globals.css`

---

## Рабочий процесс

```
1. UX       → wireframes/       (Excalidraw, обсуждаем логику)
2. Утверждение вайрфреймов
3. Дизайн   → Penpot            (чистовые макеты)
4. Экспорт  → screens/          (финальные мокапы)
              components/        (состояния компонентов)
5. Токены   → tokens.json       (дизайнер фиксирует переменные)
6. Код      → tailwind.config.ts + globals.css
```

---

## Как добавить wireframe

1. Нарисовать схему в Excalidraw
2. Save to file → `.excalidraw`
3. Положить в `wireframes/` с именем `NN-название-экрана.excalidraw`

Примеры имён: `01-auth-flow.excalidraw`, `02-recommendations.excalidraw`, `03-trails-list.excalidraw`, `04-trail-detail.excalidraw`, `05-map.excalidraw`
